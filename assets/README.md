# Logos de ASE-IA

Sube aquí los logos oficiales con **exactamente estos nombres** y aparecerán
automáticamente en `ase-ia.html` (avatar y escudo). Mientras no existan, la
página muestra una versión vectorial de respaldo.

- `robot.png` → mascota ASE-IA (idealmente PNG con fondo transparente).
- `logo-sip.png` → escudo del Colegio Presidente José Joaquín Prieto (SIP).
- `logo-sip-170.png` → logotipo "SIP Red de Colegios · 170 años", usado en el
  membrete institucional al imprimir material de PLANIFICA (planificaciones,
  guías, rúbricas, objetivos).

Opcional:
- `ase-ia-badge.png` → robot dentro del anillo de colores (versión insignia).
